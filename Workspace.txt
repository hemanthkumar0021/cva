2. Eliminating the MaxSeq Self-Join
Original Code (The grouping CTE):

SQL
MAX(CLST.CLST_SEQ_NO) Seq
...
GROUP BY CLCL.CLCL_ID, TRUNC(CLST.CLST_STS_DTM)
Optimized Code (The Window Function):

SQL
ROW_NUMBER() OVER(PARTITION BY CLCL.CLCL_ID ORDER BY CLST.CLST_SEQ_NO DESC) as rn
Why it was changed:

Reducing Table Scans: To find the final status of the day, your original query had to read the claim and status tables, group them to find the highest sequence, and then execute an INNER JOIN back to those exact same tables to get the rest of the column data.

By using ROW_NUMBER(), SQL Server assigns a sequential number to the statuses in memory (1 being the highest sequence). We can then just filter by WHERE rn = 1 in the main query. This eliminates an entire pass over those massive tables.

3. Deleting the ALL01 CTE
Original Code (The extra CTE and Join):

SQL
ALL01 as ( SELECT DISTINCT CLCL.CLCL_ID FROM ... WHERE CLST_STS = '01' )
...
INNER JOIN ALL01 ON MaxSeq.CLCL_ID = ALL01.CLCL_ID
Optimized Code (In-memory flagging):

SQL
MAX(CASE WHEN CLST.CLST_STS = '01' AND CLST.USUS_ID <> '$DEFWEB1' THEN 1 ELSE 0 END) OVER(PARTITION BY CLCL.CLCL_ID) as Has01Status
Why it was changed:

Avoiding Redundant Work: The original ALL01 CTE forced the engine to scan the tables yet again just to build a list of claims that had an '01' status.

By using the MAX(CASE...) OVER(...) window function, as SQL Server scans the tables the very first time, it looks for the '01' status. If it sees it, it stamps a 1 (Has01Status) on every row associated with that Claim ID. This completely removes the need for the ALL01 CTE and its associated join.


FINAL OPTIMIZED CODE

WITH ClaimDailyStatus AS (
    -- Read the tables exactly ONCE for yesterday's data
    SELECT 
        CLCL.CLCL_ID,
        CLCL.CLCL_ID_ADJ_FROM,
        CLCL.PRPR_ID,
        CLCL.CLCL_EOB_EXCD_ID,
        CLCL.clcl_recd_dt,
        CLCL.GRGR_CK,
        CLST.USUS_ID,
        CLST.CLST_STS,
        CLST.CLST_STS_DTM,
        -- 1. Get the latest sequence number for the claim today (rn = 1 is the final status)
        ROW_NUMBER() OVER(PARTITION BY CLCL.CLCL_ID ORDER BY CLST.CLST_SEQ_NO DESC) as rn,
        -- 2. Flag if this claim had an '01' status at any point today (excluding the specific user)
        MAX(CASE WHEN CLST.CLST_STS = '01' AND CLST.USUS_ID <> '$DEFWEB1' THEN 1 ELSE 0 END) OVER(PARTITION BY CLCL.CLCL_ID) as Has01Status
    FROM FAC.CMC_CLST_STATUS CLST
    INNER JOIN FAC.CMC_CLCL_CLAIM CLCL 
        ON CLST.CLCL_ID = CLCL.CLCL_ID
    -- 3. SQL Server SARGable date filtering for exactly yesterday
    WHERE CLST.CLST_STS_DTM >= CAST(DATEADD(day, -1, GETDATE()) AS DATE) 
      AND CLST.CLST_STS_DTM < CAST(GETDATE() AS DATE)
)

-- Main query to format the output and apply final filters
SELECT 
    CAST(STS.CLST_STS_DTM AS DATE) AS CLOSURE_DATE,
    STS.USUS_ID,
    GRGR.GRGR_ID,
    STS.CLCL_ID,
    STS.CLCL_ID_ADJ_FROM,
    STS.PRPR_ID AS TAXID,
    CASE 
        WHEN TRIM(STS.CLCL_ID_ADJ_FROM) IS NOT NULL THEN 'Y'
        WHEN STS.CLCL_ID LIKE '%GM%' AND (
            STS.CLCL_EOB_EXCD_ID IN ('A62','A98','B89','B90','B91','B92','B93','B94','B95','B96','B97','B98','B99','H29')
            OR STS.CLCL_EOB_EXCD_ID BETWEEN 'E01' AND 'E20'
        ) THEN 'Y'
        ELSE 'N' 
    END AS ADJUSTED_CLAIM_FLAG,
    STS.clcl_recd_dt
FROM ClaimDailyStatus STS
INNER JOIN FAC.CMC_GRGR_GROUP GRGR 
    ON STS.GRGR_CK = GRGR.GRGR_CK
WHERE STS.rn = 1 -- Filter: Only look at the final status row of the day
  AND (
      STS.CLST_STS = '01' -- Condition A: Ended the day in Status 01
      OR 
      (STS.CLST_STS = '02' AND STS.Has01Status = 1) -- Condition B: Ended in 02, AND had an 01 earlier
  );
